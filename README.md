# Luma

Минималистичный настольный браузер на Electron и Chromium. Интерфейс на русском языке, поиск через Google, отдельные вкладки и быстрый доступ к YouTube.

## Запуск

Установите Node.js 22.12 или новее и npm, затем выполните:

```sh
npm ci
npm start
```

На Linux требуется графическая среда и системные библиотеки Electron. При первом запуске Electron может скачать свой исполняемый файл.

## Управление

Введите адрес или поисковый запрос в адресную строку. Кнопка с домом открывает стартовую страницу. Доступны Ctrl+T, Ctrl+W, Ctrl+L, Ctrl+R, Alt+← и Alt+→ (на macOS вместо Ctrl используется Command).

## Проверки

```sh
npm test
xvfb-run -a node test/browser.integration.js
xvfb-run -a node test/memory.integration.js
```

Интеграционная проверка использует Xvfb и `--no-sandbox` для изолированной тестовой среды. Обычный запуск не отключает песочницу Chromium.

## Текущее состояние

Это первая версия, а не полная замена Chrome: пока нет менеджера закладок, расширений, синхронизации и восстановления сессий. Доступность Google и YouTube, вход в аккаунт и воспроизведение видео зависят от сети, ограничений сайтов и среды.

## Стартовая страница и вкладки

Вкладки находятся в боковой панели. Кнопка слева от адресной строки сворачивает панель. Для переключения вкладок с клавиатуры используются стрелки вверх и вниз.

Пустые вкладки используют общую локальную стартовую страницу в процессе интерфейса. Для них не создаются отдельные WebContentsView. При открытии сайта создаётся изолированная страница Chromium. Переходы назад и вперёд сохраняются и при возврате на стартовую страницу. Встраивание удалённых сайтов в интерфейс блокируется; ссылки стартовой страницы передаются основному процессу браузера.

Замер пустых вкладок на Linux:

```sh
xvfb-run -a node test/startup-benchmark.js
```

В одном из контрольных прогонов: 1 пустая вкладка — 171,5 МиБ PSS; 20 пустых вкладок — 175,1 МиБ PSS, один процесс отображения интерфейса. Это измерение в облачной среде с работающим Preview. PSS распределяет разделяемую память между процессами и зависит также от других работающих приложений. Расход сайтов и видео измеряется отдельно.

## Экономия памяти

Кнопка с листом включает и выключает автоматическую экономию. По умолчанию она включена: после 5 минут в фоне подходящая вкладка выгружается. Кнопка `zᶻ` запускает выгрузку фоновых вкладок сразу. Спящие вкладки отмечены буквой `z` и восстанавливаются при выборе вместе с историей переходов.

Вкладки с воспроизведением (включая видео без звука), доступом к устройствам, загрузками файлов, изменёнными полями формы, редактируемым содержимым, вложенными фреймами или захватом страницы сохраняются. Проверка форм консервативная, но не может распознать все виды состояния веб-приложений. При выгрузке страница загружается заново: временное состояние JavaScript может потеряться. Для работы с такими сайтами выключите автоэкономию.

Для воспроизводимого замера PSS на Linux:

```sh
xvfb-run -a node test/memory-benchmark.js
xvfb-run -a node test/memory-benchmark.js --sleep
```

Сценарий открывает шесть локальных страниц, каждая удерживает 32 МиБ данных. PSS суммируется по процессам приложения из `/proc/<pid>/smaps_rollup`; значения зависят от среды и не описывают потребление произвольных сайтов. Тесты выгрузки запускают обычный Electron без подключения DevTools: отладчик помечает страницы как захватываемые, и браузер намеренно сохраняет их активными.

## Дизайн и источники

Стартовая страница поддерживает светлую и тёмную темы. Выбор сохраняется локально. Внешние шрифты, UI-фреймворки и анимированные фоны не загружаются. Панель обновляет существующие элементы вкладок и объединяет события перед отправкой состояния.

Использованы рекомендации навыков [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) и [web-design-guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines). Восстановление истории основано на API [Electron NavigationHistory](https://www.electronjs.org/docs/latest/api/navigation-history).
